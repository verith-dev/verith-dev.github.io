# Verith

Verith builds small, focused apps for the tools teams already use — starting with
Atlassian Confluence.

The apps are built on **Atlassian Forge**, which means they run on Atlassian's own
infrastructure rather than on a vendor server. There is no Verith server, no database and
no analytics collecting anything about your instance.

## Apps

### Content Freshness — for Confluence Cloud

Shows how long ago every page was last edited, labels it *Up to date*, *Getting old* or
*Possibly outdated*, and lets authors confirm a page is still current without editing it.
A weekly scan collects everything that has gone stale into an administrator dashboard.
